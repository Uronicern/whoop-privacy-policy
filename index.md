# WHOOP Private MCP Privacy Policy

_Last updated: 2026-09-02_

This page describes the privacy practices of **Whoop Private MCP**, a personal, single-account integration operated by the GitHub account [Uronicern](https://github.com/Uronicern). It is an independent project and is not an official WHOOP product.

## Data accessed

After the account owner grants OAuth permission, the integration may access the WHOOP data covered by the selected permissions, including:

- profile information;
- body measurements;
- sleep data;
- recovery data;
- cycle data; and
- workout data.

The integration does not collect data from anyone who has not authorized it.

## Purpose and storage

The data is used only for the account owner's personal health archive, local queries, trend analysis, and optional export to the owner's Hermes/MCP workflow.

Data is intended to remain on infrastructure controlled by the owner, primarily a private mac-server running an encrypted local archive. The owner may optionally export encrypted files to a private NAS/Obsidian directory. No health data is published in this repository or on this website.

## Sharing

This personal integration does not sell health data or use it for advertising. Data is not intentionally shared with other people. WHOOP remains the upstream service that receives OAuth/API requests, and the owner-controlled mac-server or NAS may receive the owner's own data for the purposes described above.

## Security

OAuth tokens, client secrets, database keys, and encryption keys are intended to be kept in protected local storage and are not included in source code, public pages, or exported health records. No security measure can guarantee absolute security, so the owner should protect access to the mac-server, NAS, and GitHub account.

## Retention and deletion

The owner may revoke this integration through WHOOP and may delete the locally stored archive and exported files at any time. Revoking WHOOP access prevents future API access; it does not automatically delete copies already stored on owner-controlled systems.

## Contact

For questions about this personal integration, contact the operator through the [Uronicern GitHub profile](https://github.com/Uronicern).
